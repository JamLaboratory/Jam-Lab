# Jam Laboratory

An independent music journal built with Astro and deployed to Cloudflare Pages.

## Development

```bash
npm install
npm run dev
```

## Cloudflare Pages

- Framework: Astro
- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `main`
